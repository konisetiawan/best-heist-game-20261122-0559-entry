Sneak through three museum rooms in this top-down heist, evade guards and their vision cones and rotating security cameras, steal the loot, and keep the alarm meter down. Throw pebbles to distract guards, lockpick the vault, and find each room's exit.

## Run it

Serve the `game/` directory over HTTP and open it in a browser. To create the screenshots with the included Playwright script, run `NODE_PATH=/home/hatch/workspace/shot/node_modules node capture.cjs`. To run the entry renderer, use `MAKEFUN_OUTPUT_DIR=out node main.ts`.
